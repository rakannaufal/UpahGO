# Brief Produksi Aktif Upahgo

Versi 1.0, 17 November 2026. Logo pilihan pengguna menjadi sumber. **Tidak ada prompt dikirim ke model gambar; tidak membuat konsep pengganti atau memakai API berbayar.** Dokumen ini mengatur adaptasi teknis, bukan persetujuan fitur tambahan.

## Logo

```text
Use the user-selected Upahgo PNG as the visual authority.
Preserve the worker's cap, white figure, gold apron, white orbit and green badge.
Retain the original PNG byte-for-byte in source/. Do not redraw, reinterpret,
trace into a guessed vector, add letters, tools, coins or other symbols.
Sample solid UI colors from the supplied artwork: green #014C24, gold #E5C282.
Create deterministic technical crops, alpha mattes and resized PNG exports.
Remove only the outer white margin from the badge; preserve white artwork.
For the transparent emblem, separate green with chroma matting and inspect edges.
Do not label raster derivatives as vector masters or device-approved exports.
Companion wordmark: exact Upahgo, Roboto 700, licensed source retained.
Light lockup uses green text; dark lockup white. These are companion proposals.
```

## Android

```text
Derive all six native candidate exports from the same selected emblem.
Use a full square opaque #014C24 background; let the OS supply the launcher mask.
Adaptive foreground: true alpha, centered, inside a conservative central safe zone.
Adaptive background: opaque green. Monochrome: black RGB and emblem alpha.
Play icon: 512 square opaque PNG. Splash: transparent emblem; no startup delay.
Check dimensions, alpha, monochrome RGB, source hash and geometric containment.
Device mask, themed icon and Expo/Android/store compatibility remain untested.
```

## Ikon dan marker

36 Material Symbols Rounded tetap dari sumber resmi. Tidak meregenerasi glyph dengan AI. Marker pekerja mint/person/membulat; pemberi kerja emas/work/kotak lembut. Outline hijau, selected lebih tebal. Label dan alternatif daftar tetap wajib. Source SVG dan PNG 1x/2x/3x dibuat dari token yang sama; tanpa loop.

## Studi visual

Tampilkan fondasi, state komponen, WorkerCard/EmployerCard bertag, onboarding, penemuan, dan izin kontak. Beri label gambar statis dan data simulasi. Peta contoh adalah diagram area, bukan basemap nyata. Tanpa foto, rating, jumlah pengguna, klaim verifikasi atau keamanan palsu. Pembayaran tunai di tempat; WhatsApp sesudah consent dan dibuka manual. Rincian: [DESIGN.md](../DESIGN.md).

## Pembersihan

Draf logo ditolak dan turunannya dihapus sesuai otorisasi terdahulu; tidak membuat arsip pengganti. Pertahankan sumber terpilih, glyph/font berlisensi, marker dan dokumen. Gambar referensi di folder sementara pengguna tidak dihapus. Ilustrasi ditunda.
